# Template-video privacy notice

Source photos are relayed through the existing bounded cache to the
operator-controlled Intel Mac. Metadata is stripped. Photos, embeddings,
frames and scratch files are not added to chat memory, RAG, analytics or a
reusable face library. Unpaid inputs expire quickly; admitted inputs are
removed after completion or within the configured job window. Ready outputs
are available through authenticated access for 600 seconds.

The job record stores a versioned consent attestation, source hashes, bounded
job state and an opaque output provenance identifier. This record is not a
rights determination. Cache expiry and unlinking do not promise secure erasure
from every SSD snapshot or backup, and copies downloaded by a user cannot be
revoked.

Privacy requests and urgent source-media concerns go to
`privacy@swiveltechnologies.in`. A public named Grievance Officer must be
added before any legal obligation requiring one is relied upon; no name is
invented by this document.
