# Delivery, refund and retention contract

One paid generation is ₹25 (2500 paise), separate from Chat and Voice
credits. A ready result is available through authenticated access for 600
seconds from readiness. Queue estimates are measured ranges, not guarantees;
email delivery is best effort and never extends expiry.

If an infrastructure failure prevents delivery, the existing refund and
complimentary-allowance reconciliation path applies exactly once. Ambiguous
payment-provider responses are reconciled rather than blindly retried. This
feature does not convert video refunds into Chat or Voice credits and does not
change weekly Chat credits or subscriptions.

Source media and scratch files use the existing bounded retention policy.
Downloaded copies are outside Swico's control. The operator must disclose any
residual backup/SSD retention before enabling a public rollout.
